# 0.254.0 — Insane Reveal Overhaul

This release upgrades the feel of every meaningful card flip without touching odds or save data.

## New reveal language
- **Holo / reverse**: clean reflective sheen and soft glow.
- **EX / Double Rare / ACE SPEC**: stronger burst, satisfying pulse, and brighter highlight sweep.
- **Ultra / Illustration / Radiant**: prismatic energy, richer color rays, and premium impact.
- **Chase / SIR**: high-drama reveal with cleaner premium lighting, bold particles, and lightning strikes.
- **Apex / Gold / Secret**: bigger aura, stronger spotlight, premium badge, and more intense effects.
- **God Pack**: biggest lighting burst, multi-bolt strike, and full celebratory FX stack.
