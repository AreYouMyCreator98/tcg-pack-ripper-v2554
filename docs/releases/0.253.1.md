# 0.253.1 — Pack Engine Polish

This patch fixes the issues confirmed on Android after V253 shipped.

- Session value now reconciles against the final resolved pack value shown in the completion screen.
- FAST / SESSION / SIR+ HUD is positioned below the clock row instead of behind the mobile set shelf.
- Reveal All now says `N TO COLLECT`, because the action includes the currently displayed uncollected card.
- Pack-complete UI is compacted for phones: duplicate legacy stat tiles are hidden, the pull fan remains, the V253 recap becomes the main data panel, navigation is hidden under the modal, and the screen can scroll safely on shorter devices.
- Reset Session Stats is visually secondary.

No pull-rate, reward, economy, routing, account or save-schema changes are included.
