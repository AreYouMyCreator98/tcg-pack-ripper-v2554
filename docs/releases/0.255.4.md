# V255.4 — System reliability

- Binder taps no longer get redirected by the swipe controller.
- Repeated or stale Sell requests cannot double-pay or sell missing inventory.
- Failed ten-pack generation restores affected payment/progression state and suppresses provisional session events.
- Missing card pools exit safely; rejected generation releases the opening UI.
- Reveal All retries cannot duplicate cards after a finish-render failure.
- Account and multiplayer share one Supabase client.
- Required-hit audits include expansion subsets and distinguish network failures from missing cards.
- Artwork repair preserves ownership on HTTP 404; late pack artwork cannot overwrite another selected set.
- Current save envelopes retain metadata; future schemas are rejected instead of downgraded.
- Invalid numeric pack metadata cannot poison counters.
- Windows validation paths fixed; dependencies pinned with a lockfile.
- Service worker preserves unrelated caches and the production manifest includes the real bundled entry point.
- Production bundles read the precache during an outage; validated with the local server stopped.
- Faded notifications no longer intercept collection navigation taps.
- Listing and cash summaries refresh immediately when market inventory changes.
- Pack recaps explicitly identify minimum-price estimates.

See ../VERIFICATION-V2554.md for measured coverage and remaining gaps.
