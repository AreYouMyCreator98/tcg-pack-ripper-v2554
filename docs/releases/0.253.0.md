# 0.253.0 — Pack Engine + Reveal 2.0

V253 begins the pack-system extraction without changing the live probability generator.

## Architecture
- Added `src/packs/` modular pack engine, session, recap, rate snapshot and generator contract.
- Added `src/animations/packs/` reveal and 10-pack controllers.
- Added `runtime/pack-bridge.js` as the only new direct dependency on legacy pack globals.
- The bridge loads after the proven V252 critical runtime and failure falls back to the legacy pack flow instead of blocking startup.

## Player-facing features
- Fast Reveal toggle skips long hit cinematics while preserving the normal hit card and effects.
- 10-pack Reveal All uses a two-tap confirmation and collects only the uncollected range.
- Session HUD shows packs opened plus SIR+/God Pack streak counters.
- Enhanced pack recap shows best pull, pack value, hits, Binder/Bulk routing, payment source and rarity breakdown.
- Session totals include packs, hit packs, generated value, cash spent and new cards.

## Safety
- V252 pull-rate constants remain untouched; V253's rate module is descriptive and tested against the live generator source.
- Generated-pack contract requires exactly ten card records per pack.
- Reveal All routes from the current card index onward and then uses the existing batch-finish path.
- Save schema remains version 1.
