# V255 — Multiplayer Arena

## Ranked Quick Match
A match being found no longer immediately opens the battle. Both collectors enter a ready lobby. Each player may choose their unlocked battle set, configure their Profile identity beforehand, and press READY. The server blocks pack progress/results until both players are ready.

When both players lock in, both devices play a synchronized-feeling VS presentation showing:
- collector display name
- Profile picture
- equipped season/ranked frame
- chosen banner title and visual style
- up to three selected earned badges
- current server-ranked RP and W/L/T record

## Profile Battle Banner
Profile now contains a Battle Banner editor. Players can select six styles, choose up to three earned badges, set a short banner title, and choose whether their ranked record is shown. Their existing Profile picture and equipped ranked frame are used automatically.

## Global Chat
The Battle & Trade panel gains a realtime Global Chat with:
- live messages
- realtime online presence count
- unread counter
- 180-character cap
- server-side rate limits
- local mute controls

## Multiplayer hardening
- Public ranked stats are recalculated from completed matchmaking rooms server-side.
- Matchmade pack progress and result submission are rejected until both players are ready.
- Abandoned matched rooms that never ready are cleaned up after a timeout.
- The existing server result/winner flow remains the source of battle outcomes.

No pack pull rates, collection data, economy values or save schema are changed.

## Compatibility cleanup
The full regression run caught a V254 reveal-profile compatibility field that the V253 session tracker still expects. V255 restores that metadata so SIR+ session counters/streaks remain correct without changing the V254 reveal visuals or any pull probabilities.
