# Archived V255 online implementation

These files are retained only for comparison with the replacement. They are not in the runtime manifest, public directory or production cache. The associated historical source assertions are in `tests/legacy/`; they describe the retired version and are excluded from current release validation. V256 has behavioral database, controller, DOM integration and cloud-barrier tests instead.

`integrate-hub.mjs` is the one-time extraction script used during development. Do not run it on V256; later improvements have replaced its generated output.
